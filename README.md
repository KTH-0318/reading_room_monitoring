# 실시간 열람실 모니터링 시스템

라즈베리파이 + YOLOv8n + 환경센서로 열람실 좌석의 실사용 여부와 온·습도·불쾌지수·미세먼지를
실시간 웹 대시보드로 제공한 IoT 모니터링 시스템.
**얼굴 대신 책상 위 물건을 탐지**해 프라이버시 부담을 줄였고, **실제 열람실 72석에 배포·시연**했습니다.

소프트웨어 인재육성 캠프 **동상** · 5인 팀(조원: 센서 연결 · SQL 서버 관리 · 대시보드 담당)

## 시스템 구성
(기존 다이어그램 그대로 유지)

- 좌석 점유 판정: 책상 구역 분할 → 물건(노트북·책·펜 등) 5초 이상 감지 시 "사용 중"
- 모델: 라즈베리파이 메모리 제약에 맞춘 최경량 **YOLOv8n**
- 한계: 짐만 두고 자리를 비우면 여전히 "사용 중"으로 판정 → 물건 종류·지속시간 조건 정교화 필요
